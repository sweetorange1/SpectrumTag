# Change history

2026-11-14: source version raised to **2.0.2**. The spectrum right-click now prints the unprinted image, returns a focused Print to image mode, or focuses the nearest Print when nothing is focused; the unprinted preview replaces the white card with a transparent ink overlay that attenuates the spectrum underneath; and a new Grayscale mode attenuates each frequency/time cell by pixel luminance. Colour images select Grayscale automatically and re-fit contrast/brightness from that image (no inheritance, biased darker, pure black always fully cut). Print edits store the grayscale settings (SPT6 record format, ARA state). Verified with SpectrumTagStandalone / SpectrumTag_VST3 / SpectrumTagVerify builds, `--checks` (1.4.8 / right-click / grayscale), `--checks201` / `--checks202` / `--checks1410` / `--checks1412` / `--checks1421` and the standalone `--fileless-ui-test`; no 2.0.2 installers were produced.

2026-11-12: source version raised to **2.0.1**. Image objects now have three explicit states (unprinted / printed / focused) replacing the old click-to-print model; dragging a printed object returns it to the image state in one gesture and no longer flashes a black column while the new raster arrives; the Print button under the image is a rounded rectangle with a border; the no-audio banner sits in the middle of the spectrum area; the language, diagnostics and audio-device buttons share one outline style (border only, no fill); Ctrl-drag leaves a Print in place and drags a copy, Ctrl+C / Ctrl+V copy an object and paste a copy at the playhead (a focused Print stays printed), and a copy/paste button sits right of Delete; the previous/next Print arrows appear only when several Prints exist and are bare icons; the Range dropdown is hidden and new instances default to 22.05 kHz. `build_installer.bat` now takes the installer version from CMakeLists.txt instead of a hard-coded 1.4.3, and `reset_first_run.bat` restores the first-launch state. Verified with SpectrumTagStandalone / SpectrumTag_VST3 / SpectrumTagVerify builds, the fileless UI regression and the targeted 1.4.x checks; no 2.0.1 installers were produced.

2026-11-10: source version raised to **2.0.0**. The interface was rebuilt on the existing visual language: flat styling for every JUCE text button, Noto Sans SC Black (heaviest available face) with a measured optical size compensation for Chinese, a vector play/pause icon in the standalone, Stop removed, the load button renamed to "Load audio", and Clear moved to a right-aligned trash icon. Verified with SpectrumTag_VST3 / SpectrumTagStandalone builds and the fileless UI regression; no 2.0.0 installers were produced yet.

2026-11-09: the user designated **1.4.28 Stable**, requested a new Plan B before publishing, then Windows/macOS installers with bilingual TXT guides and an incremental upstream PR. The delivered Windows standalone is reused; additional platforms/installers were pending at designation and subsequently passed the checks recorded in `docs/INSTALLERS_1.4.28.md`. See `docs/STABLE_1.4.28.md`.

2026-11-08: the user designated the delivered **1.4.27 Stable** and requested a new Plan B source snapshot. The existing Windows and macOS installers, product version and verification are reused; only status/documentation changes. The reported Mac Print display issue remains under investigation, and installer destination changes are deferred by the user. See `docs/STABLE_1.4.27.md`.

2026-11-07: the user designated the delivered Windows standalone **1.4.24 Stable** and requested a new Plan B source snapshot. This is a status/documentation change only; the existing EXE and version are retained. See `docs/STABLE_1.4.24.md`. The earlier version history below retains its original identities.

This is a concise record of the Windows development delivered after upstream 1.4.3. Features were iterated during development; the README and handoff describe the current behaviour. Windows plugins 1.4.18 and standalone 1.4.19 were designated Stable on 2026-11-06. Earlier Stable decisions and delivery versions are not retroactively renamed.
